Persone del team

Password di accesso

Le password sono sempre due: una per l'Admin e una per tutti i Guest. La password Guest è quella standard, valida solo al primo accesso: ogni Guest deve poi sceglierne una personale (vedi sotto).

Amministratori

Gli Admin entrano con la password Admin (la stessa per tutti). Se scrivi un nome già presente nell'elenco, quella persona diventa Admin; altrimenti viene creata come Admin. Rimuovendo un Admin torna Guest e dovrà scegliere una password personale al primo accesso.

Password personali dei Guest

Ogni Guest, al primo accesso, sostituisce la password standard con una propria. Qui l'Admin vede la password aggiornata. "Reimposta" cancella la password personale: la persona dovrà rientrare con quella standard e sceglierne una nuova. Le password sono salvate in questo browser.

Dati di prova

Per ora i dati di esempio restano nell'app, così puoi usarli per la presentazione. Quando hai finito, qui puoi eliminarli. Ogni eliminazione chiede una seconda pressione per confermare. Le password non vengono toccate.

Gli appuntamenti dei progetti da importare nel calendario di Outlook.

Compatibile con Outlook 365 e 2019

Come importare nel calendario di Outlook

Calendario .ics. Se lo ricevi dentro uno zip, estrailo prima. Poi fai doppio clic sul file .ics: Outlook propone di aggiungerlo al calendario. In alternativa, in Outlook classico (2019 o 365) vai su File, Apri ed esporta, Importa/Esporta, Importa un file iCalendar. Nel nuovo Outlook e in Outlook sul web vai su Calendario, Aggiungi calendario, Carica da file. Conviene importarlo in un calendario nuovo, così puoi eliminarlo in blocco se serve.
